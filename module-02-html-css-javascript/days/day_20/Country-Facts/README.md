# Country Facts Page

A simple single-page application that fetches live country information using the REST Countries API.

## Features

- Search for a country
- Default country is Ethiopia
- Displays country name
- Displays flag
- Displays capital
- Displays population
- Displays region
- Displays currencies
- Shows a loading state
- Shows friendly error messages
- Uses async/await
- Uses try/catch
- Checks response with res.ok

## API

REST Countries API:

https://restcountries.com/v3.1/name/{country}

## How to Run

1. Clone or download the repository.
2. Open the `country-facts` folder in VS Code.
3. Open `index.html` with Live Server.
4. The page will initially display Ethiopia.
5. Enter another country and click Search.
