# Addis Market Shopping List

# Description

Addis Market is a simple interactive shopping list built with HTML, CSS, and JavaScript.

The application allows users to:

- Add an item with its ETB price
- Validate the item name and price
- Mark an item as bought
- Delete an item
- See the running total of all item prices

# Technologies

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Event Handling
- Event Delegation

# How to Open

Open index.html in a web browser.

You can also use VS Code Live Server to run the project.
