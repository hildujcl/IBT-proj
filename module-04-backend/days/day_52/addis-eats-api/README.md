# Addis Eats API - Day 52

A TypeScript project demonstrating type aliases,
union types, readonly properties, optional properties,
switch statements, exhaustive checking, and
international currency formatting.

## Technologies

- TypeScript
- Node.js
- npm
- CommonJS

## Features

- Delivery area union types
- Order status union types
- Dish and Order type definitions
- Delivery fee calculation
- Order status messages
- Receipt generation
- ETB currency formatting
- Exhaustive type checking
