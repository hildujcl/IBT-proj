# 🍓 Addis Eats Tracker

Addis Eats Tracker is a delivery tracking web application built
with Next.js and React. It provides a simple and attractive way
to follow a sample food delivery in Addis Ababa.

## ✨ Features

- Interactive delivery map using Leaflet and OpenStreetMap.
- Courier and delivery destination markers.
- Simulated order status updates using Server-Sent Events (SSE).
- Order progress timeline.
- Delivery information and order summary.
- Ethiopian birr (ETB) currency formatting.
- Addis Ababa date and time formatting.
- CSV order history export.
- Basic CSV file type and size validation.
- Responsive pink-themed user interface.

## 🛠️ Technologies

- Next.js
- React
- JavaScript
- Tailwind CSS
- Leaflet
- React Leaflet
- OpenStreetMap
- Server-Sent Events (SSE)
