# Addis Eats ♡

Addis Eats is a responsive Ethiopian food ordering
web application built with Next.js and React.

The project allows customers to explore traditional
Ethiopian dishes, search and filter the menu, add food
to a shopping cart, and place demo orders.

## Features

- Responsive lavender and pink user interface
- Ethiopian food menu
- Food search and category filtering
- Individual dish detail pages
- Shopping cart with quantity controls
- Customer registration and authentication demo
- Signed session cookies
- Protected pages using Next.js Proxy
- Server-side session and role checks
- Order creation and order status management
- Administrator kitchen dashboard
- API routes for menu, authentication, and orders
- SWR data fetching and automatic revalidation
- Dynamic metadata and Open Graph images
- Robots.txt and XML sitemap

## Technology Stack

- Next.js
- React
- JavaScript
- Tailwind CSS
- SWR
- Node.js
- CSS
- Browser localStorage
